FOX AI 연구소 공식 사이트와 관리자 CMS

2026 · 사내, 1명
JavaScript, Google Apps Script, GitHub API·Pages2026년 6월부터 운영 중

문제
공지 한 줄을 고칠 때마다 제가 코드를 고치고 본사에 서버 업로드를 요청해야 했습니다(4단계).
해결
직원이 직접 고치는 관리자 CMS를 만들었습니다. 바뀌는 내용만 JSON으로 빼서 GitHub Pages에 두고 토큰은 Apps Script 안에 숨겼으며, 저장 직전에 버전을 비교해 동시 수정 시 덮어쓰기를 막았습니다.
결과
저장 후 1~2분 안에 반영되고, 도입 첫 주 12건이 저를 거치지 않고 올라갔습니다. 페이지 용량은 1,766KB에서 578KB로 67% 줄였습니다.

우송대학교 RISE U-늘봄 강사 양성 누리집

2026 · 외부 의뢰, 1명
Node.js, Express, SQLite, Jest, GitHub Actions

문제
점검표를 모두 통과해 납품한 뒤, 부하 테스트로 다시 점검하자 여러 신청이 동시에 들어올 때 정원이 초과되는 문제가 드러났습니다.
해결
인원 확인과 저장을 하나의 트랜잭션으로 묶고, 비밀번호 검증을 비동기 방식으로 바꿨습니다. Jest 테스트 16개와 GitHub Actions로 수정할 때마다 자동 검증합니다.
결과
정원 30명 과정에 50명이 동시에 신청해도 초과 접수 0건, 로그인 처리량은 초당 12건에서 85건으로 늘었습니다.
