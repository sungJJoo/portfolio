C언어 은행 관리 프로그램

장려상2024.12 (3주)

이노베이션 아카데미 Codyssey C언어 과정에서 3명이 3주 동안 만든 콘솔 프로그램입니다. 외부 라이브러리 없이 C 표준 함수와 Windows 콘솔 기능만 썼고, 우송대학교 첨단산업인재양성 경진대회에서 장려상을 받았습니다.

첨단산업인재양성 경진대회 장려상

원래 윈도우 콘솔용이라 키 입력, 화면 지우기, 잠깐 멈추기 세 가지만 리눅스용으로 바꿔 끼워 실행하고 녹화했습니다.

기능 구성

회원가입, 로그인아이디 중복 검사, 비밀번호 가림→ 계좌 개설은행 코드 + 연도 + 난수, 1인 5개까지→ 입금, 출금, 송금잔액 확인, 같은 계좌 송금 차단→ 거래 내역계좌마다 최근 20건
JSON 파일 저장과 불러오기DB 없이 읽기와 쓰기를 직접 구현

Overview

C언어 과정에서 배운 구조체, 배열, 파일 입출력만으로 은행 업무를 흉내 내는 프로그램을 만들었습니다. 방향키로 메뉴를 고르고 ESC로 뒤로 가는 콘솔 화면을 커서 위치를 지정해 직접 그렸습니다.

Key Features

  • 회원가입(아이디 중복 검사, 비밀번호 가림), 로그인
  • 계좌 개설: 하나은행·농협은행 코드와 연도, 난수로 계좌번호 생성
  • 입금, 출금, 송금: 잔액 확인, 받는 사람과 계좌 선택, 같은 계좌로 보내기 차단
  • 거래 내역: 계좌마다 최근 20건을 남기고 오래된 것부터 밀어냄
  • 저장: JSON 형식 읽기와 쓰기를 직접 짜서 파일에 저장하고 다시 불러옴

Iterations

주마다 고친 것을 발표 자료에 남겼습니다.

  • 회원가입 때 아이디 중복 방지, 비밀번호를 * 로 가려 표시
  • 화면 초기화 부분을 고쳐 사양이 낮은 컴퓨터에서도 원활하게 동작
  • 송금할 때 계좌 번호를 검사해 받는 계좌가 겹치지 않게 함
  • 메뉴 추가

Looking Back

비밀번호를 그대로 저장한 점이 가장 큰 약점이었습니다. 발표 때 다음 과제로 DB 적용, 계좌 종류 추가, 관리자 모드, 파일 분할, 보안 수정을 적었습니다.
