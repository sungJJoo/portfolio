# 박성주 포트폴리오

기획부터 구현·운영까지 혼자 끝내는 개발자, 박성주의 포트폴리오 사이트입니다.

**사이트**: https://sungjjoo.github.io/portfolio/

## 구성
- `index.html` — 한 페이지 포트폴리오 (소개 · 프로젝트 · 경력 · 기술 · 연락)
- `assets/style.css` — 밝은 테마, 반응형(900px · 600px 기준)
- `assets/main.js` — 스크롤 등장 효과 (동작 줄이기 설정 존중)
- `assets/fonts/` — Pretendard Variable 동적 서브셋 자체 호스팅 (SIL OFL 1.1)

프레임워크와 빌드 과정 없이 정적 파일만으로 GitHub Pages에서 동작합니다.
